# Educational Use and Acceptable-Use Notice

AutoCliper is a final-year student capstone project. Its purpose is to
demonstrate full-stack engineering, media processing, transcript analysis,
background jobs, cloud storage, and opt-in social publishing in a controlled
learning environment.

## Allowed learning use

Use this project with:

- videos you created or own;
- videos for which you have written permission;
- media whose license expressly permits the intended processing and sharing;
- test media created specifically for development and evaluation.

## Prohibited use

Do not use this project to:

- bypass DRM, authentication, paywalls, private links, or access controls;
- evade platform rate limits, security controls, or content enforcement;
- mass-download, scrape, spam, harass, impersonate, or redistribute content;
- publish clips without reviewing the source license and the final output;
- connect accounts or credentials that you do not own or have authority to use.
